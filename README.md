# 🏫 Universal High School Kisaasi Website

**🌐 Live site:** https://ignatiusari.github.io/universal-high-kisaasi-website/

## 💡 Overview

Parents search for schools on their phones before they ever visit. This project gives **Universal High School Kisaasi** (Kisaasi, Kampala, Uganda) a fast, mobile-friendly website that works as a 24/7 admissions information desk for parents in Uganda and abroad. They can see programmes, fees, admission requirements and alumni, and contact the school in one tap by call, WhatsApp or email.

It is built by **Arinaitwe Ignatius**, software developer, as a real-client capstone project for the HTML and CSS course at **Custospark Company Ltd**, under the guidance of the Technical Coach, **Opiyo Oscar**, from 22 October to 7 November 2026.
